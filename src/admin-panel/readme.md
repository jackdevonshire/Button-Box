# Admin Panel

## Running

Double-click `start.bat` (or run it from a terminal). On first run it creates a virtual environment in `.venv` and installs `requirements.txt`; dependencies are reinstalled automatically whenever `requirements.txt` changes. The panel is then served at http://localhost.

Requires Python 3 on Windows (the keyboard integration uses PyDirectInput).
